About OpenShelf

A modern home for software discovery.

OpenShelf is designed around a simple idea: people should be able to find an app, understand what it is, see the version they want, and know where the file comes from.

DiscoverSearch, categories, featured apps and fast app pages.
Compare versionsKeep latest and previous releases organized on one page.
Be transparentClearly label official, publisher and community sources.
Scale laterThe frontend can be connected to a real database and admin backend when needed.
Important

Only publish files and links you are authorized to distribute. OpenShelf can display source and license information to help keep listings clear.
